# Algorithms Assignment

This repository contains my Algorithms assignment covering four main topics:

1. What is an Algorithm?
2. Types of Algorithms
3. Growth of Functions
4. Complexity

The assignment is based primarily on *Discrete Mathematics and Its Applications* (8th Edition), Chapter 3, by Kenneth H. Rosen.

## Repository Contents

| File | Description |
|---|---|
| `Algorithms_Assignment.pdf` | Final assignment document |
| `Algorithms_Assignment.tex` | LaTeX source file |
| `Algorithms_Assignment.ipynb` | Jupyter Notebook with implementations and analysis |
| `dashboard.html` | Interactive assignment dashboard |
| `chart.min.js` | JavaScript chart library used by the dashboard |

## Interactive Dashboard

The dashboard provides an interactive presentation of the assignment topics, including algorithm demonstrations, growth of functions, and complexity analysis.

**Live Dashboard:** [View Algorithms Dashboard](https://dashboardzip.vercel.app)

## How to View the Dashboard Locally

1. Download or clone this repository.
2. Keep `dashboard.html` and `chart.min.js` together in the same folder.
3. Open `dashboard.html` in a web browser.
